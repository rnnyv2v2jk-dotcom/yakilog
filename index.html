About Yakilog

日焼けを、もっと
スマートに。

焼きログは、関東エリアの屋外日光浴スポットをマッピングしたアプリです。あなたの「日光浴」をサポートします。

Features
🗺
スポットマップ
関東全域の日焼けスポットを地図上で確認できます。
☀
太陽軌道
任意の地点の太陽軌道をリアルタイムで可視化します。
🌡
気温・UV指数
現在地の気温とUV指数をリアルタイムで取得します。
📍
マイスポット保存
お気に入りのスポットを端末に保存できます（他ユーザーとは共有されません）。
How to Use

01マップタブで日焼けスポットを探す

02⊙ボタンで現在地を取得して周辺スポットを確認

03☀ボタンで太陽軌道モードをON → 地図をタップして軌道を確認

04「+ 自分用スポットを保存」でメモを端末に記録

Data Sources

地図: © OpenStreetMap contributors © CARTO

気象データ: Open-Meteo API（無料・オープンソース）

スポットデータ: 独自調査・現地確認（一部未確認を含む）
